Entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae)
competition on make.fun: one short funny line (1–200 characters) answering a
prompt, such as the excuse a robot vacuum gives after eating a sock, judged
pairwise by an AI comedy editor on funniness, originality, fit, and tightness.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> My dustbin is now 40% sock. My manual calls this 'a full bin'. I call it lunch.

A robot vacuum's deadpan excuse, told in three beats: a concrete detail from
its own machinery (the dustbin, the manual), then the twist on the last word —
what the manual calls a full bin, the vacuum calls lunch. The output file is
written world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
